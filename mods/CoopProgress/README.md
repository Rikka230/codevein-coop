# CoopProgress

UE4SS Lua mod: what a guest misses in co-op, and (off by default) giving it to him. Same build as the rest of this repo
(Steam 1.53.93354, exe SHA-256 `8fa550fe…e0e172`). Discussion and findings: [#1](https://github.com/eight8pac/codevein-coop/issues/1).

**Status:** tested in solo play only (offline, 2026-10-28). Never run in a two-player session.

## Step 1: observe (always on)

Read-only; it does not touch the session. Each event goes to the UE4SS log and, with `journal=1`, to
`journal.txt` in the mod folder (tab-separated: time, role `solo`/`host`/`guest`, kind, details).

| Kind | Source |
|---|---|
| `REWARDS` | `BossAreaBase:MulticastGainRewards`: the area, its defeat symbol and its four reward lists (`BossAreaRewards`, `BossAreaRewardsToGuest`, `CooperativePlayRewardToHost/ToGuest`). Fires once per boss phase. |
| `FLAG` | Changes in `UGameProgressFlagTable` (`BoolMap`, `ValMap`, ~2,000 entries), read every 2 s; also script calls to `SetGameProgress(Int)`. |
| `LOAD` | More than 50 flag changes at once (a save was loaded): new baseline, no detail. |
| `POSITION` | Main story position: the last true symbol of `main_progress.txt` (195 symbols, from `DT_ProgressSymbol`'s MainProgress rows). |
| `GAP` | A true story symbol after a false one, which would break the one-position model. Never seen so far. |

`main_progress.txt` is generated by `tools/progresssymbols.py <paks dir> --main mods/CoopProgress/main_progress.txt`.

## Install

Copy the `CoopProgress` folder, including `main_progress.txt`, to `ue4ss\Mods\` and add `CoopProgress : 1` to `mods.txt`
(and `mods.json`). Tested with UE4SS v3.0.1-1183 (1181 is no longer published) and `HookLoadMap = 0`.

## Steps 2 and 3 (off by default)

The boss area is a level actor, so on the guest's own game `MulticastGainRewards` runs with the area's reward lists and
defeat symbol: no network channel is needed for bosses. On the last boss phase only (`IsLastPhase`):

- `guest_rewards=1`: when `BossAreaRewardsToGuest` is empty, give the guest the `BossAreaRewards` entries, items through
  `CharacterHelper:GainItem`, weapons through `UpdateWeaponInventoryInfo`; once per `defeatSymbol|article` (`ledger.txt`).
- `guest_progress=1`: if the defeat symbol is on the main line and ahead of the guest, `SetGameProgress(symbol, ctx, true)`.
  Never moves back.
- Before the first write of a game run, every `.sav` under `%LOCALAPPDATA%\CodeVein\Saved\SaveGames` is copied to
  `backups\<time>\`; if that fails, nothing is written.
- `solo_as_guest=1` runs this in solo play, for tests only (the player then gets the boss item twice).

Only the guest needs steps 2 and 3 on; the host can keep them off.

Tested in solo with `solo_as_guest=1` on SubBoss_St07: backup, halberd given, ledger, position 71 → 73; a second session
skipped the halberd from the ledger. The "not the last phase" wait was seen on Boss_St07 phase 1. Not run in co-op yet.
Known limits: the ledger is per installation, not per save slot; story progress outside boss kills (cutscenes, areas)
still needs a host → guest channel.
